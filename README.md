# Portfólio - Estevam Robinson Dias Neto

Projeto desenvolvido para a atividade prática de Fundamentos da Programação Web.

## Tecnologias
- HTML5
- CSS3 puro
- JavaScript puro

## Páginas
- `index.html` - Sobre mim
- `formacao.html` - Formação
- `portfolio.html` - Portfólio
- `contato.html` - Contato

## Funcionalidades JavaScript
- Menu responsivo.
- Alternância entre tema claro e escuro.
- Validação de nome, e-mail e mensagem.
- Simulação de envio do formulário.
